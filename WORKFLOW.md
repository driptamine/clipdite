# Workflow

## Push

После каждой выполненной задачи изменения обязательно коммитятся и пушатся
в `main` на GitHub — без напоминания:

```bash
git add <файлы по именам>
git commit -m "<что сделано>"
git push origin main
```

- Коммитить только свои изменённые/созданные файлы, по именам (без `git add -A`).
- Не трогать чужие следы: `.gitignore`, `.github/` и прочие файлы,
  изменённые не в рамках задачи, в коммит не брать.
- Сообщение коммита — на английском, с кратким списком что сделано.
- Проверка перед пушем: `npx tsc -b`, `npx oxlint`, `npm run build` — всё чисто.
